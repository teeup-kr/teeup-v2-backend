## 테스트 실행 체크리스트

각 모임별로 다음을 확인:

1. **편성 모드 확인**: 선택한 편성 모드가 올바르게 적용되었는지
2. **팀 개수 확인**: 예상 팀 개수와 일치하는지
3. **팀 인원수 확인**: 각 팀이 3인조 또는 4인조로 올바르게 구성되었는지
4. **성별 분리 확인**: 성별 분리 모드인 경우 남녀가 분리되었는지
5. **성별 혼합 확인**: 성별 혼합 모드인 경우 남녀가 혼합되었는지
6. **핸디캡 균형 확인**: 핸디캡 기준 모드인 경우 팀 간 핸디캡 총합이 비슷한지
7. **성적 순서 확인**: 직전대회 성적 기준 모드인 경우 성적 순서가 반영되었는지
8. **랜덤 확인**: 랜덤 모드인 경우 무작위로 배정되었는지

## 참고사항

- 성별 분리 모드 테스트 시: 남자 4명 이상, 여자 4명 이상 필요
- 직전대회 성적 기준 모드: 직전대회 성적 데이터가 있는 참가자만 사용 가능
- 게스트 추가: 인원 부족 시 게스트를 추가하여 테스트 가능
- 모집 마감 전: 팀 편성 불가, 반드시 마감 후 진행
